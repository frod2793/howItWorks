## 프로필과 영향 범위

`.agents/config/project-profile.conf`는 구현 경계를 설명하기 위한 참고 계약이며 제품 요구가 특정 기술 선택을 강제하지 않게 합니다.

| 항목 | 현재 값 | 제품 영향 |
|------|---------|-----------|
| `confirmation_status` | [pending/confirmed] | [결정된 범위] |
| `architecture` | [값] | [선택 프로필의 역할] |
| `dependency_injection` | [값 또는 `none`] | [`none`을 포함한 지원 제약] |
| `${source_root}` | [모든 값] | 기능 영향 범위 |
| `${test_root}` | [모든 값 또는 N/A] | 수용 검증 범위 |

| 선택 프로필의 역할 | 클래스 | 사용자 가치와의 관계 |

| 기법 | 적용 상태 | 측정 근거 | 롤백 조건 |
|------|-----------|-----------|-----------|
