# 제품 스펙 관리 가이드

## 언제 제품 스펙을 만드는가?

- 새로운 게임 기능 기획 시
- 기존 기능의 대규모 개선 시
- 기획팀과 개발팀 간 합의가 필요한 기능

## 파일 네이밍 규칙

```
YYYY-MM-DD-기능명-spec.md
```

예시:
- `2026-07-02-player-combat-spec.md`
- `2026-07-02-gacha-system-spec.md`

## 작성 프로세스

1. `_TEMPLATE.md`를 복사하여 새 파일 생성
2. 기획 내용을 유저 스토리와 요구사항으로 정리
3. 성능 기준 수치 명시
4. 리뷰 후 승인
5. 승인된 스펙을 기반으로 `docs/design-docs/`에 설계 문서 작성

## 설계 문서와의 관계

```
제품 스펙 (What) → 설계 문서 (How) → 실행 계획 (Step-by-step)
```

제품 스펙은 **무엇**을 만들지 정의하고, 설계 문서는 **어떻게** 만들지 정의합니다.
