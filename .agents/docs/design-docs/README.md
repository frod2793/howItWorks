# 설계 문서 작성 가이드

## 언제 설계 문서를 만드는가?

다음 중 하나에 해당하면 설계 문서를 작성합니다:

- 새로운 기능 또는 시스템 구현 시
- 기존 아키텍처를 변경하는 리팩토링 시
- 여러 씬/시스템에 영향을 미치는 변경 시
- 디자인 패턴 도입 또는 변경 시

## 파일 네이밍 규칙

```
YYYY-MM-DD-기능명-design.md
```

예시:
- `2026-07-02-player-combat-design.md`
- `2026-07-02-inventory-system-design.md`

## 작성 프로세스

1. `_TEMPLATE.md`를 복사하여 새 파일 생성
2. 모든 섹션 작성 (빈 섹션 없이)
3. 리뷰 요청 (상태를 🔍로 변경)
4. 승인 후 구현 시작 (상태를 ✅로 변경)

## 필수 확인 사항

- [ ] MVVM 데이터 흐름이 단방향으로 설계되었는가?
- [ ] View → Model 직접 참조가 없는가?
- [ ] VContainer 등록 방식이 규칙을 준수하는가?
- [ ] 싱글톤 패턴을 사용하지 않았는가?
- [ ] DTO 패턴이 필요한 곳에 적용되었는가?
