# macOS BSD awk 한글 문자열 비교 오판

- 증상: 서로 다른 한글 마크다운 헤딩 두 개가 awk의 `==` 비교에서 같다고 판정되어 문서 섹션 추출 테스트가 잘못된 섹션을 읽고 실패했습니다.
- 환경: macOS 기본(BSD) awk, `en_US.UTF-8` 로케일. 한글 대 한글 비교에서만 발생하며 한글 대 ASCII 비교는 안전했습니다.
- 원인: BSD awk가 UTF-8 로케일에서 문자열 비교에 strcoll 계열 정렬 비교를 사용해, 정렬 가중치가 같은 서로 다른 한글 문자열을 동일하다고 판정했습니다.
- 해결: 한글 문자열끼리 비교하는 awk 호출에 `LC_ALL=C awk` 접두를 적용해 바이트 비교를 강제했습니다.
- 검증: 두 한글 헤딩의 `==` 오판을 대화형 awk로 재현하고, `LC_ALL=C` 적용 후 같은 입력에서 오판이 사라짐과 전체 테스트 스위트 통과를 확인했습니다.
- 재발 방지: 테스트 스위트의 마크다운 섹션 추출·enum 계수 지점에 `LC_ALL=C` 고정. 새 awk 코드에 한글 리터럴 비교가 있으면 같은 접두를 사용합니다.
- 승격 상태: 승격 완료 — 테스트 스위트(`tests/run-tests.sh`)에 적용됨.
