# NULLOVE - 콘텐츠 설계서 (Content Specification Document)

본 문서는 디스토피아 시간 루프 비주얼 노벨 **NULLOVE**의 인게임 정적 데이터 및 동적 콘텐츠 시스템 사양을 명세합니다. 본 설계서는 인게임 데이터 DTO 및 JSON 스키마 설계의 직접적인 기준이 됩니다.

---

## 1. 개요 및 기획 방향성

### 1.1. 기본 정보
- **프로젝트명**: NULLOVE (A Loop Has No Love)
- **장르**: 디스토피아 시간 루프 비주얼 노벨 / 텍스트 어드벤처
- **플랫폼**: PC (Windows 10/11, macOS 12+ / Steam)
- **해상도**: FHD 1920 × 1080 (PC 가로형)

### 1.2. 로그라인 (Logline)
> 감정이 금지된 완벽한 도시에서, 카토를 거부한 한 학생이 시간이 멈춘 진실과 마주한다.

### 1.3. 핵심 기획 기둥 (Core Pillars)
1. **감정의 비용 (Emotion & Risk)**: 감정을 강하게 느낄수록 통제 도시의 감시망이 좁혀오며, 진실에 다가가는 동시에 즉각적인 위험에 노출되는 역설적 구조.
2. **반복의 층위 (Layers of Loop)**: 시간 루프가 반복될 때마다 단순히 대사가 반복되는 것이 아니라, 씬의 맥락, 캐릭터의 태도, 일러스트의 아우라가 누적 변형되는 다회차 시스템.
3. **선택의 무게 (Weight of Choice)**: 10개의 핵심 분기점과 9개의 멀티 엔딩을 통해 사소한 아이템 획득과 약물 복용 여부가 결말의 나비효과를 일으킴.
4. **관계의 메아리 (Echo of Relations)**: 시간선을 초월하여 이어지는 야만인 구역 생존자들과의 인연과 신뢰도 시스템.

## 2. 스토리 및 씬(Scene) 매트릭스 설계

게임은 메인 스토리 16개 씬과 보조/회차 변형 씬 12개를 합쳐 **총 28개 씬**으로 구성됩니다.

| **SC_02** | 통제선 옆 | 메인 | 울타리 통제 경계. **분기점 1**: 경계 접근 시 '짚 인형' 발견 가능. |

| **SC_08** | 카토 위기 | 메인 | 감시도 축적으로 인한 경고 상태. **분기점 4**: 강제 카토 복용 선택지. |

| **SC_10** | 지하 라디오 | 보조 | 시아의 지하 무전실. 라디오 부품 전달 시 서브플롯 활성. |
| **SC_11** | 카토 공장 | 보조 | 유진과의 만남. 짚 인형 전달 시 유진의 정체 해금. |

| **SC_16** | 최종 문 | 메인 | 마지막 시간의 문. 루프 탈출 또는 새로운 제어 장치화. |

### 2.2. 분기점 매트릭스 (10대 핵심 분기점)
1. **분기_01 (씬 2)**: 울타리 아래 단서를 수색할 것인가? (짚 인형 획득 여부)
2. **분기_02 (씬 5)**: 제이의 검문에서 주머니 속 단서를 숨길 것인가? (단서 유실 방지)
3. **분기_03 (씬 7)**: 렌과 함께 움직일 것인가, 단독 행동할 것인가? (렌 신뢰도 변동)
4. **분기_04 (씬 8)**: 매일 아침 제공되는 카토를 복용할 것인가? (카토 복용/거부)
5. **분기_05 (씬 10)**: 라디오 부품을 시아에게 기부할 것인가? (라디오 서브플롯 활성)
6. **분기_06 (씬 11)**: 유진에게 짚 인형의 매듭을 보여줄 것인가? (유진 서브플롯 활성)
7. **분기_07 (씬 11.5)**: 현우의 장갑으로 지문 도어락을 해제할 것인가? (공장 심부 진입)
8. **분기_08 (씬 13)**: 대면(CONF) 시 엘레나의 유서(편지 조각)를 제시할 것인가?
9. **분기_09 (씬 13)**: 대면(CONF) 시 지배자에게 '그리움'을 투영할 것인가?
10. **분기_10 (씬 16)**: 시간의 문 너머로 아라와 함께 나아갈 것인가? (진엔딩 vs 도피엔딩)

### 2.3. 엔딩 루트 명세 (9종)
- **엔딩 A (순응 - 붕괴)**: 카토를 단 한 번도 거부하지 않고 복용하여 완전히 감정이 마비되어 자아가 붕괴됨.
- **엔딩 B (타협 - 계승)**: 제이의 제안을 수락하여 도시의 새로운 감시관으로 복직함.
- **엔딩 C (체념 - 반복)**: 지배자를 대면했으나 설득에 실패하고, 진실을 침묵한 채 다음 루프(회차+1)를 강제 시작함.
- **엔딩 D (도피 - 잠적)**: 아라와 함께 장벽을 넘어 야만인 구역 깊숙한 곳으로 도망쳐 정착함.
- **엔딩 E (소멸 - 망각)**: 지배자가 도시의 모든 인간의 감정 시스템을 일괄 포맷하여 기억과 감정이 소멸됨.
- **엔딩 F (희생 - 봉헌)**: 시간의 제어 장치인 지배자를 대신하여 스스로가 루프의 핵(Core)이 됨.
- **엔딩 G (공존 - 다리)**: 도시의 감시 시스템을 정지시키고 야만인 구역과의 경계 장벽을 허물어 공존을 택함.
- **엔딩 H (해방 - 진엔딩)**: 그리움 상태에서 지배자를 해방하고 시간의 문을 파괴하여 멈춰버린 내일을 되찾음.
- **엔딩 I (제재 - 강제종료)**: 인게임 도중 감시도가 10에 도달하여 관리국에 의해 영구 강제 포맷 처리됨 (배드엔딩).

## 4. 자원 및 감정(EMO) 시스템 수치 설계

### 4.1. 감정 5축 및 합성 감정
주인공의 감정 상태는 5가지 축으로 구성되며, 런타임에 **0에서 10 사이의 정수**로 관리됩니다.

1. **슬픔 (Sorrow)**: 상실을 인지할 때 상승.
2. **기쁨 (Joy)**: 아라 및 야만인들과의 소통을 통해 상승.
3. **호기심 (Curiosity)**: 단서 획득 및 수색 행동 시 상승.
4. **공포 (Fear)**: 검문, 경고, 거부 행위 누적 시 상승.
5. **혼란 (Confusion)**: 다회차 기시감 및 모순 직면 시 상승.

#### 그리움 (Yearning) 합성 공식
- **활성화 조건**: `Sorrow >= 3` 이고 `Joy >= 3`
- **시스템 효과**: 
  - `IsYearningActive = true`
  - HUD 방사형 감정 레이더 그래프 중앙에 황금빛 '그리움' 이펙트 표출.
  - 지배자 대면(CONF) 시, 3번 대면 카드인 **'느끼다(FEEL)'**가 잠금 해제됨.

### 4.2. 카토(CATO) 및 자원 변동 매트릭스
매일 아침 주인공에게 제공되는 카토(CATO)를 복용하느냐, 혹은 거부하느냐에 따라 플레이어의 주요 능력치와 자원이 변경됩니다.

| 자원 종류 | 표기 범위 | 시작값 | 주요 변동 요인 | 수치 도달 효과 |
| :--- | :---: | :---: | :--- | :--- |
| **카토 재고** | 0 ~ 5 | 2 | 매일 아침 배급(+1), 복용 시(-1) | 0 도달 시: 감정 억제 불가 상태 돌입 |
| **감시도** | 0 ~ 10 | 0 | 카토 거부(+1), 불법 단서 소지(+1), 감정 폭주 | 10 도달 시: 씬 9 강제 체포 및 엔딩 I 행 |
| **신뢰도** | 0 ~ 10 | 0 | 야만인 친화 선택지(+1), 지원 행위 | 7 이상: 지배자 본부 진입 시 야만인 지원 |
| **회차 인식도** | 0 ~ 5 | 0 | 엔딩 도달 및 루프 반복 시 (+1) | 4 이상: CONF '놓아주다' 카드 해금 |

#### 복용 / 거부 행동 결과 매트릭스
- **카토 복용 (Take Cato)**:
  - 카토 재고: `-1`
  - 감정 5축: 전체 수치 `Clamp(Value - 2, 0, 10)` (감정 마비)
  - 감시도: `Clamp(Surveillance - 1, 0, 10)`
  - 회차 인식도 경험치: 변동 없음.
- **카토 거부 (Refuse Cato)**:
  - 카토 재고: 변동 없음 (주머니에 누적)
  - 감정 5축: 전체 수치 `Clamp(Value + 1.5, 0, 10)` (감정 민감화)
  - 감시도: `Clamp(Surveillance + 1, 0, 10)`
  - 회차 인식도 경험치: `+10%` 즉시 누적.
  - **특수 이벤트**: 당일 밤 취침 시 **'꿈(SC_03)'** 시퀀스로 강제 진입하여 노파/전달자로부터 단서를 획득하게 됨.

## 5. 인벤토리 수집 단서 및 아이템 설계

아이템은 3가지 탭(단서, 쪽지, 열쇠)으로 구분되며, UI 상에서 스토리 및 엔딩에 미치는 영향도에 따라 특수 마커가 표시됩니다.

### 5.1. 영향도 UI 마커 규칙
- **일반 (Normal)**: 마커 없음. 세계관 텍스트 및 기본 정보 제공.
- **분기 영향 (Subplot/Branch)**: **◆ (다이아몬드)** 마커. 특정 서브플롯 진행도를 올리거나 숨겨진 보조 씬을 해금함.
- **진엔딩 조건 (True Ending Core)**: **★ (별)** 마커. 진엔딩 '해방' 루트 진입에 반드시 인벤토리에 소지해야 함.

### 5.2. 핵심 수집 아이템 리스트
1. **짚 인형 (Straw Doll)**
   - **분류**: 단서 | **마커**: ◆
   - **획득 경로**: 씬 2 통제선 옆 통제 울타리 아래 수색.
   - **연동 데이터**: 유진 환생 서브플롯 진행도 +25%, 노인의 정체 서브플롯 진행도 +15% 누적.
2. **낡은 서류 #1 (Old Documents #1)**
   - **분류**: 쪽지 | **마커**: 없음
   - **획득 경로**: 씬 9 침수 문서고 책상 위.
   - **연동 데이터**: 도시의 설립 이력 및 감정 통제 구상 초안 제공.
3. **마야 노트 (Maya's Diary)**
   - **분류**: 쪽지 | **마커**: ◆
   - **획득 경로**: 씬 11 카토 공장 보관함.
   - **연동 데이터**: 닥터 K가 진행했던 초기 약물 인체 실험의 부작용 및 오류 로그.
4. **라디오 부품 (Radio Transmitters)**
   - **분류**: 열쇠 | **마커**: ◆
   - **획득 경로**: 씬 5 제이와의 검문을 무사히 통과한 후 보상 획득.
   - **연동 데이터**: 시아의 지하 무선 라디오 서브플롯 해금에 사용.
5. **현우의 작업 장갑 (Hyunwoo's Gloves)**
   - **분류**: 열쇠 | **마커**: ◆
   - **획득 경로**: 씬 11.5 카토 공장 하부 폐기 통로.
   - **연동 데이터**: 카토 공장 제어실의 생체 인식 센서를 통과하기 위한 도구.
6. **찢어진 편지 조각 (Torn Letter Fragment)**
   - **분류**: 쪽지 | **마커**: ★
   - **획득 경로**: 회차 인식도 3 이상인 상태로 씬 3(꿈)에서 노파에게 획득.
   - **연동 데이터**: 엘레나가 지배자에게 남긴 마지막 편지 조각. CONF 대면 시 '기억하다' 카드 사용 권한 획득.

## 6. 대면(CONF) 카드 및 선택지 설계

씬 13 지배자와의 클라이맥스 조우 시, 플레이어는 일반 선택지 대신 **4가지 대면 카드(CONF Card)** 중 하나를 선택해 인터랙션을 진행해야 합니다.

### 6.1. 대면 카드 속성 테이블
| 카드 ID | 카드 명칭 | 연결 액션 | 잠금 해제 조건 | 판정 결과 |
| :---: | :--- | :---: | :--- | :--- |
| **01** | **대화하다 (TALK)** | 대화 진행 | 상시 해금 (기본 카드) | 지배자의 자기 정당화 대사 출력. 대화 게이지 소폭 상승. |
| **02** | **기억하다 (REMEMBER)** | 엘레나 상기 | 인벤토리에 '찢어진 편지 조각' 소지 | 지배자의 분노 상태 유발. 엔딩 C2(타협 또는 대치) 진입. |
| **03** | **느끼다 (FEEL)** | 감정 투영 | 그리움 (IsYearningActive == true) | 지배자의 감정 동기화. 루프의 구조적 균열 발생. 엔딩 C3 진입. |
| **04** | **놓아주다 (LET GO)** | 해방/파괴 | 누적 엔딩 >= 2종 AND 회차 인식도 >= 4 | 루프의 핵 정지. 최종 진엔딩(H_해방)으로 가는 문 해금. |

## 7. 회차(LOOP) 변형 매트릭스

회차가 누적(0 ~ 5)됨에 따라 시간선 내의 데이터 및 연출이 동적으로 변화합니다.

### 7.1. 회차 인식도 수치별 연출 변화
- **인식도 0 (최초 플레이)**:
  - 대사: 규격화된 디스토피아 텍스트 출력.
  - 일러스트: 기본 채도.
  - 배경음: 1레이어 BGM (베이스만 재생).
- **인식도 1**:
  - 대사: 주인공의 독백에 미세한 기시감 텍스트 삽입 ("이 장면을 전에도 본 것 같다").
  - 배경음: 2레이어 BGM (베이스 + 멜로디).
- **인식도 2**:
  - 이벤트: 씬 3 꿈 진입 시 전달자의 외형 실루엣이 조금 더 뚜렷해짐.
  - 아이템: 짚 인형의 텍스트 설명에 노인의 매듭 기법 추가 묘사 해금.
- **인식도 3**:
  - 씬 변형: 씬 9 침수 문서고의 기록관이 주인공을 이전 회차의 태도로 맞이함.
  - 획득: 꿈 시퀀스에서 '찢어진 편지 조각' 획득 가능 상태 해금.
- **인식도 4**:
  - 연출: UI 좌측 자원 패널에 감시도 경고 붉은 아우라 추가.
  - CONF: '놓아주다' 카드 사용 가능 상태로 전이 시작.
  - 배경음: 3레이어 BGM (베이스 + 멜로디 + 환경음 합성 완성).
- **인식도 5 (최대치)**:
  - 기능 해금: 백로그 화면에서 단 한 번만 이전 씬의 임의 선택지로 돌아갈 수 있는 **'시간 왜곡(Scene Rollback)'** 버튼이 활성화됨. (이로 인해 한 회차 내에서 여러 보조 분기를 즉각 테스트할 수 있게 됨)

### 7.2. 영속성 데이터 저장 스키마
단일 세이브 데이터와 별도로, 회차가 끝나도 지워지지 않는 글로벌 진행도 파일의 저장 속성은 다음과 같습니다.

```csharp
[System.Serializable]
public class GlobalProgressDTO
{
    public int AccumulatePlayCount;      // 누적 회차 진행 수
    public int MaxLoopAwareness;         // 달성한 최대 회차 인식도 (0~5)
    public bool[] AchievedEndings;       // 엔딩 A~I 달성 플래그 배열 (크기 9)
    public List<string> UnlockedClues;   // 도감에 해금된 단서 ID 목록
    public List<string> MetCharacters;   // 도감에 해금된 캐릭터 ID 목록
    public int ClearedSubplotsCount;     // 완료한 서브플롯 개수 (최대 5)
    public bool[] AchievedAchievements;  // 도전과제 달성 여부 (크기 24)
}
```
